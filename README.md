# All Smiles Dental — Sitio Web

Sitio web oficial de **All Smiles Dental**, consultorio de odontología estética 
de la Dra. Nohelia Reyes Cuéllar en Santa Cruz de la Sierra, Bolivia.

🌐 Sitio en vivo: https://all-smiles-dental.com

## Estructura
- `index.html` — página principal (todo el sitio es de una sola página)
- `images/` — fotos, logo e imágenes de servicios
- `sitemap.xml` / `robots.txt` — archivos de indexación para buscadores
- `CNAME` — conecta el repositorio con el dominio personalizado

## Cómo editar
Este sitio es HTML/CSS puro, sin frameworks. Para hacer cambios, edita 
`index.html` directamente y sube (`push`) los cambios a la rama `main`; 
GitHub Pages actualiza el sitio automáticamente en 1-2 minutos.
